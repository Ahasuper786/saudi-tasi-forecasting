## Featured project

### Saudi TASI Return Forecasting

Built a release-aware forecasting pipeline to test whether Saudi macro-financial, commodity and trade indicators improve one-month-ahead TASI return forecasts beyond market history alone.

- Compared Zero-Return, Historical-Mean, AutoReg(12), Random Forest and XGBoost
- Used 16 predictors across four nested information sets
- Evaluated with a chronological holdout and 76 expanding-window forecasts
- XGBoost achieved fixed-test MAE of **3.049**
- Random Forest achieved fixed-test RMSE of **4.044** and **63.33%** directional accuracy
- Longer walk-forward testing showed the ML advantage was not stable over time
